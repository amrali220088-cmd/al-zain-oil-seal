# AL ZAIN OIL SEAL — موقع متجر تجريبي

## تشغيل الموقع
1. فك ضغط الملف ZIP.
2. افتح مجلد `al_zain_oil_seal` على الكمبيوتر.
3. افتح `index.html` بالنقر المزدوج، أو افتح المجلد في Visual Studio Code واستخدم إضافة Live Server.

## قبل النشر واستقبال طلبات حقيقية
1. افتح `script.js`.
2. في بداية الملف ابحث عن:
   `whatsappNumber: "201000000000"`
3. استبدل الرقم برقم واتساب الشركة بصيغة دولية، أرقام فقط، بدون `+` أو مسافات. مثال مصر: `201xxxxxxxxx`.
4. عدّل قائمة المنتجات والأسعار التجريبية في مصفوفة `products` داخل `script.js`.
5. عدّل فقرة «عن الشركة» في `index.html` وأضف بيانات الشركة الرسمية.
6. جرّب إضافة منتجات للسلة، تغيير الكمية، طلب عرض السعر، والتأكد من فتح واتساب.

## ملاحظات مهمة
- المنتجات والأسعار المعروضة أمثلة تجريبية وليست قائمة أسعار مؤكدة من الشركة.
- الموقع لا يعالج الدفع الإلكتروني ولا يحفظ الطلبات على خادم؛ يجهز رسالة يرسلها العميل بنفسه عبر واتساب.
- لتشغيل متجر فعلي واسع النطاق ستحتاج لاحقًا إلى استضافة، نطاق، وإدارة مخزون/طلبات آمنة.
- صور المنتجات ممثلة برسومات رمزية CSS/Unicode لتعمل الملفات مباشرة دون صور خارجية.
